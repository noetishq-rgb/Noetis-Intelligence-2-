# Single-dollar website research pilot

The production pilot uses a dedicated service login bound to exactly one brand. Its credentials and Claude key remain in Vercel Production secrets. The existing GitHub worker workflow can explicitly invoke `research_pilot=status` or `research_pilot=run` using signed OIDC; schedules and pushes cannot run this pilot. A status invocation checks model metadata without generating text. No email, discovery, social or planning call is made.

Before a paid request, the latest profile must be confirmed through the existing onboarding/approval process, with no critical unanswered inputs. The service cannot approve profiles or synthesize missing client answers. Client setup submission alone does not approve the research intake. The monthly marketing budget is distinct from the pilot's API allowance.

The pilot reuses at most five successful stored website captures, preserves their original capture timestamps, and selects verbatim text windows. Regional relevance requires explicit captured text; a `.in` domain is insufficient. The dossier must identify absent independent market, audience and competitor evidence. Deterministic provenance validation and human semantic review remain required.

Pricing is pinned to standard uncached `claude-sonnet-4-6`: USD 3 per million input tokens and USD 15 per million output tokens, verified against Anthropic's pricing page on 2026-11-17. Maximum input is 16,000 and maximum generated output is 4,096 tokens. Admission reserves an input safety margin and refuses a reservation above USD 1. No prompt caching, thinking budget, search or other paid tools are enabled. Token cost excludes taxes and unrelated usage outside this app. INR cost remains unavailable until explicit reporting exchange rates are configured; USD is not mislabeled as INR.

Admission checks durable dispatch history under the workflow lock and allows one generation attempt for the configured brand. A failed or uncertain attempt still consumes that allowance. Pilot jobs also have `max_attempts=1`; repeated dispatches return the existing job. Lost leases retain the existing uncertain-charge handling. No automatic re-generation or approval occurs. To authorize another pilot, change this policy deliberately after reviewing usage; merely rerunning Actions cannot spend again.

Configuration: `MI_MODEL_PROVIDER=anthropic`, `MI_ANTHROPIC_MODEL=claude-sonnet-4-6`, `MI_ALLOW_MODEL_CALLS=true`, `MI_RESEARCH_PILOT_ENABLED=true`, `MI_RESEARCH_PILOT_BRAND_ID`, `MI_RESEARCH_PILOT_SERVICE_USER_ID`, and `MI_RESEARCH_PILOT_WORKER_DATABASE_URL`. Keep `MI_ALLOW_PLANNING_CALLS=false` and `MI_ALLOW_SEARCH_CALLS=false`. Production credentials must not be given to previews. The pilot-specific dollar admission remains active for the configured brand even if the invocation flag is subsequently switched off.
